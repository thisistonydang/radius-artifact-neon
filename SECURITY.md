# Security policy

## Supported version

Only the latest commit on `main` and the current live Radius artifact are supported.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/thisistonydang/radius-artifact-neon/security/advisories/new). Do not open a public issue for a security problem or include credentials, tokens, personal data, or exploit details in a public report.

Please avoid destructive testing, automated account creation, high-volume AI requests, or high-volume file uploads against the live demo.
